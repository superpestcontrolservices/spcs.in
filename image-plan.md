## 4. Deterministic selection and technical/SEO checklist for Step 2

1. Select from the page’s matching subject pool first. For broad district/locality pages without a clear pest topic, use an appropriate general service image. Hash the normalized page slug to rotate within that pool; use a separate deterministic offset for hero and supporting slots. Never repeat a file on one page, and do not count the identical wood-borer duplicate as a separate choice.
2. Write natural, image-specific alt text of 8–15 words for each content image, based on the verified visible subject; include a district/area name only when natural. Use more than one phrasing pattern. Do not infer an unverified location, treatment result, or claim from a filename.
3. For an above-the-fold hero, use explicit intrinsic `width` and `height`, `loading="eager"`, `fetchpriority="high"`, and `decoding="async"`. For supporting images, use explicit dimensions, `loading="lazy"`, and `decoding="async"`. Use responsive sizing, `aspect-ratio`, and `object-fit: cover` in existing-compatible styling.
4. Use root-relative local URLs under `/images/`. Add/update `og:image`, `twitter:image`, and the existing JSON-LD image URL without removing or rewriting unrelated schema. Use absolute `https://superpest.in/...` URLs for metadata.
5. Extend the existing sitemap with image entries for images used on each affected page. Do not add an unrelated sitemap or alter page URLs.
6. Before page changes, make a targeted backup: this workspace is not currently a Git repository, so a Git branch is unavailable.
7. Validate local `src`/`srcset` paths, unique newly placed images per page, descriptive alt text, dimensions, and metadata/sitemap references. Report any preserved pre-existing duplicate images separately; do not claim a site-wide zero-duplicate result unless those existing figures are later approved for editing. Expected final checks: zero broken image paths, zero missing content-image alt text, zero missing content-image dimensions, and zero duplicate newly placed images on a page.
